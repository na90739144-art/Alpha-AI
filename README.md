# ترجمه‌گر حرفه‌ای | Pro Translator AI

این بسته شامل **همهٔ فایل‌های لازم** برای اپ شماست: فرانت‌اند (PWA)، بک‌اند امن (که کلید API را کاملاً مخفی نگه می‌دارد)، و پیکربندی ساخت خودکار APK با GitHub Actions.

⚠️ **همهٔ فایل‌ها داخل این zip به‌صورت مسطح (flat) و بدون پوشه هستند** چون خواستید. اما گیت‌هاب برای اجرای صحیح، به مسیر دقیق فایل‌ها نیاز دارد (مخصوصاً `.github/workflows/`). پس هنگام ساخت ریپازیتوری، هر فایل را دقیقاً در مسیری که جدول زیر می‌گوید قرار دهید. نام هر فایل نشان‌دهندهٔ مسیر نهایی آن با جداکنندهٔ `---` است.

## ✅ کاری که همین الان کامل و نهایی شده

- **کلید Groq API به‌کلی از فرانت‌اند حذف شد.** هیچ‌جای `index.html` کلیدی وجود ندارد.
- کلید فقط در `backend/server.js` و از طریق متغیر محیطی `GROQ_API_KEY` خوانده می‌شود — این مقدار را **هرگز در کد نمی‌نویسید**، بلکه در پنل هاست بک‌اند (یا GitHub Secret) تعریف می‌کنید. حتی خود شما هم بعد از ثبت، آن را در کد نمی‌بینید.
- نام برنامه در همه‌جا (عنوان صفحه، مانیفست، سایدبار، صفحهٔ ورود) به **«ترجمه‌گر حرفه‌ای» / Pro Translator AI** تغییر کرد.
- امکانات پیاده‌سازی‌شده: ورود/ثبت‌نام محلی، چت هوش مصنوعی با ۷ حالت (عمومی، برنامه‌نویسی، آموزش، نویسندگی، ترجمه، تحلیل فایل، تحلیل متن)، حافظهٔ مکالمه، کپی/اشتراک/خواندن پاسخ، پیوست فایل PDF/TXT، ورودی صوتی، مترجم متن با ۱۳ زبان، مترجم PDF کامل با نوار پیشرفت و خروجی دانلودی، دستیار صوتی تمام‌صفحه، تاریخچهٔ جست‌وجوپذیر، پروفایل، و تنظیمات (زبان رابط، زبان پاسخ AI، صدا).

## ⚠️ کاری که غیرممکن است من از اینجا انجام دهم (نیاز به اقدام شما دارد)

این‌ها فنی هستند و **هیچ ابزاری** (نه من، نه هیچ AI دیگری) نمی‌تواند بدون حساب و مجوزهای شخصی شما انجامشان دهد:

1. **هاست بک‌اند** — کد آماده است، اما باید آن را در یک سرویس (مثلاً Render.com یا Railway.app، هر دو پلن رایگان دارند) دیپلوی کنید و `GROQ_API_KEY` را در تنظیمات همان سرویس وارد کنید.
2. **هاست فرانت‌اند** — پوشهٔ `frontend` را در Netlify یا GitHub Pages دیپلوی کنید تا یک دامنهٔ HTTPS بگیرد.
3. بعد از گرفتن آدرس بک‌اند، **یک خط** در `frontend/index.html` را ویرایش کنید:
   ```js
   const API_BASE_URL = "https://آدرس-بک‌اند-شما/api";
   ```
4. **ورود با Google واقعی** — نیاز به OAuth Client ID از Google Cloud Console دارد (رایگان ولی نیاز به حساب گوگل شما).
5. **ساخت APK** — فایل `.github/workflows/build-apk.yml` این کار را در سرورهای گیت‌هاب خودکار انجام می‌دهد، اما اول باید:
   - در `android/twa-manifest.json` مقدار `host`, `iconUrl`, `webManifestUrl` را با دامنهٔ واقعی فرانت‌اندتان جایگزین کنید.
   - یک کلید امضا (keystore) بسازید و آن را به‌صورت Base64 در GitHub Secret به نام `ANDROID_KEYSTORE_BASE64` (+ سه Secret دیگر که در خود فایل workflow توضیح داده شده) ذخیره کنید.
   - اگر workflow با خطا مواجه شد (ابزار Bubblewrap گاهی به محیط حساس است)، ساده‌ترین جایگزین سرویس رایگان **PWABuilder.com** است: فقط آدرس سایتتان را وارد کنید و روی «Package for Android» بزنید — بدون نیاز به هیچ تنظیم گیت‌هابی.
6. **انتشار در Google Play / بازار / مایکت** — هرکدام نیاز به ثبت‌نام توسعه‌دهنده (گوگل‌پلی ۲۵ دلار یک‌بار، بازار و مایکت رایگان)، آپلود دستی APK، و تکمیل فرم‌های سیاست حریم‌خصوصی دارد. این مرحلهٔ نهایی را فقط خودتان (یا وکیل/نمایندهٔ قانونی کسب‌وکارتان) می‌توانید انجام دهید.

## 🚀 ترتیب پیشنهادی اجرا

1. ریپو گیت‌هاب بسازید و فایل‌ها را طبق جدول بالا در مسیرهای درست قرار دهید.
2. `backend` را در Render/Railway دیپلوی کنید و `GROQ_API_KEY` را آنجا تنظیم کنید.
3. `frontend` را در Netlify دیپلوی کنید.
4. خط `API_BASE_URL` در `index.html` را با آدرس بک‌اند بروزرسانی و دوباره دیپلوی کنید.
5. `android/twa-manifest.json` را با دامنهٔ فرانت‌اند بروزرسانی کنید.
6. برای APK: یا workflow گیت‌هاب را اجرا کنید (`Actions` → `Build Android APK (TWA)` → `Run workflow`)، یا از PWABuilder.com استفاده کنید.
7. APK نهایی را دانلود، تست، و برای انتشار در مارکت‌های مدنظرتان آپلود کنید.
