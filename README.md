# ALPHA Pro - هوش مصنوعی حرفه‌ای

سایت **حرفه‌ای** برای چت و ترجمه با هوش مصنوعی!

## ✨ ویژگی‌ها

✅ **طراحی حرفه‌ای** - مشکی + طلایی لوکس
✅ **Groq AI** - هوش مصنوعی پیشرفته (Mixtral)
✅ **۸ زبان** - فارسی، انگلیسی، عربی، اردو، ترکی، کردی، آذری، چینی
✅ **ترجمه متن** - ترجمه فوری و دقیق
✅ **Text-to-Speech** - خواندن متن به صوت
✅ **چت AI** - کنار زدن سوالات پیچیده
✅ **PWA** - مثل اپ روی گوشی
✅ **Offline** - بدون اینترنت کار می‌کند

## 🔧 تکنولوژی

- **Frontend:** HTML5, CSS3, Vanilla JS
- **API:** Groq (Mixtral 8x7B)

- **PWA:** Service Worker, Web App Manifest
- **Styling:** CSS Grid, Flexbox, Gradients

## 🎯 راهنمای استفاده

### **چت**
1. پیام بنویسید
2. Enter یا ارسال
3. ALPHA جواب می‌دهد
4. دکمه 🔊 برای خواندن

### **ترجمه**
1. متن را وارد کنید
2. زبان را انتخاب کنید
3. "ترجمه کن" بزنید
4. "🔊 بخوانید" برای صوت

## 📱 روی گوشی

1. لینک را باز کنید
2. Menu → "Add to Home Screen"
3. اپلیکیشن ثابت شود!
